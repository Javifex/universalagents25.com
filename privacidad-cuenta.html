TUS DATOS, CON CLARIDAD

Este aviso explica el tratamiento actual de los datos de tu cuenta y tu perfil en Universal Agents 25.

Actualizado el 23 de octubre de 2026.

Contactar con soporte ↗

Privacidad de tu cuenta

La misma cuenta se usa para las intenciones de contratar y ofrecer. El registro y el perfil están disponibles; las funciones de contratación y agentes de IA siguen en desarrollo.

Registro y acceso

Supabase Auth gestiona tu correo electrónico, tu identificador de usuario y el hash de tu contraseña para autenticarte. Usamos el correo para identificar tu cuenta y enviar enlaces de confirmación o recuperación de acceso.

La sesión se guarda en tu navegador para mantener el acceso hasta que cierres sesión o expire. Si usas un equipo compartido, cierra sesión al terminar.

Datos de tu perfil

La base de datos PostgreSQL de Supabase guarda el nombre, la biografía y la visibilidad que elijas, asociados con tu identificador y la fecha de registro. Puedes modificar tu perfil desde tu cuenta.

El perfil es privado al crearlo. Si activas «Hacer público mi perfil», cualquier persona podrá consultar su identificador (UUID), nombre, biografía y fecha de registro. El correo no se muestra en el perfil público. Evita incluir datos sensibles en la biografía.

Proveedores y datos técnicos

Supabase proporciona la autenticación y la base de datos del proyecto en la región us-east-1 de Estados Unidos. GitHub Pages y Cloudflare sirven y distribuyen la web. Estos servicios procesan los datos técnicos necesarios para responder a las solicitudes, como la dirección IP y la información de conexión y del navegador.

Funciones de IA

Las funciones de creación y ejecución de agentes siguen en desarrollo. Completar tu perfil no inicia ningún aprendizaje automático a partir de sus datos.

Ayuda, corrección o eliminación

Para recibir ayuda con tu cuenta o solicitar la corrección o eliminación de tus datos, escribe a soporte@universalagents25.com.
